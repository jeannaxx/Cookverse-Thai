## เป้าหมายรอบนี้

ทำต้นแบบเมนู **ผัดกะเพราไก่** ให้ผู้เล่นทำภารกิจตั้งแต่รับงาน เก็บวัตถุดิบ เตรียม ปรุง เสิร์ฟ และรับผลประเมิน โดยต่อยอดจากระบบที่มีแล้ว:

```text
Krapow.prefab
→ CollectionZone_Krapow
→ IngredientCollector
→ CollectionFeedbackUI
```

รอบแรกให้ทำระบบตามกฎที่แน่นอนก่อน ยังไม่ใช้ AI ตัดสิน Gameplay และยังไม่ต้องทำโมเดลสวย

## เรื่องราวและภารกิจ

ผู้เล่นมาเรียนทำอาหารที่บ้านของ **ป้าแสง** เจ้าของบ้านและครัว ป้าแสงมอบภารกิจให้ทำผัดกะเพราไก่หนึ่งจาน ผู้เล่นต้องเก็บกะเพราและพริกจากสวน นำวัตถุดิบกลับเข้าครัว เตรียมและปรุงให้ถูกลำดับ แล้วนำอาหารไปส่งให้ป้าแสงประเมิน

| `chicken` | เนื้อไก่ | 1 Portion | ตู้เย็น | Raw, Collected, Cut, Cooked |
| `cooking_oil` | น้ำมัน | 1 Portion | สถานีเครื่องปรุง | Raw, AddedToPan |
| `oyster_sauce` | ซอสหอยนางรม | 1 Portion | สถานีเครื่องปรุง | Raw, AddedToPan |

`Portion` ในต้นแบบหมายถึงวัตถุหนึ่งชิ้นหรือการกดใช้หนึ่งครั้ง ไม่ใช่หน่วยชั่งจริง

### ความเข้ากันได้กับระบบเดิม

- Prefab เดิมชื่อ `Krapow` และ `IngredientCollector` ปัจจุบันตรวจชื่อ `Krapow`
- ระยะต่อไปให้เพิ่มคอมโพเนนต์ระบุตัวตนวัตถุดิบ แล้วเก็บ `ingredientId = krapow_leaf`
- ระหว่างเปลี่ยนผ่านให้ยอมรับทั้งชื่อวัตถุ `Krapow` และ `ingredientId` ใหม่ เพื่อไม่ทำให้ Correct/Wrong flow เดิมเสีย
- ห้ามเปลี่ยนชื่อหรือลบ Prefab เดิมจนกว่าระบบ `ingredientId` จะผ่านการทดสอบ

## สถานะวัตถุดิบกลาง

ใช้ชื่อสถานะชุดเดียวกันทุก Script:

```text
Raw
Collected
Washed
Cut
AddedToPan
Cooking
Cooked
Burned
Served
```

กฎสำคัญ:

- วัตถุดิบหนึ่งชิ้นมี `ingredientId` เดียวและมี Instance ID สำหรับกันการนับซ้ำ
- `Washed` และ `Cut` ใช้เฉพาะวัตถุดิบที่ขั้นตอนกำหนด
- ไก่ห้ามเปลี่ยนเป็น `Cooked` จากการรอเฉย ๆ ต้องอยู่ในกระทะที่เปิดไฟตามเวลาที่กำหนด
- เมื่อเป็น `Burned` แล้วห้ามย้อนกลับเป็น `Cooked`
- Reset ต้องคืนวัตถุดิบ ตำแหน่ง สถานะ จำนวน และ Objective ทุกอย่าง

## ลำดับการปรุงสำหรับระบบกฎ

1. เปิดไฟและวางกระทะ
2. เติมน้ำมัน
3. ใส่กระเทียมและพริก
4. คนเครื่องหอมอย่างน้อยหนึ่งครั้ง
5. ใส่ไก่
6. ปรุงจนไก่สุก
7. เติมซอสหอยนางรม น้ำปลา และน้ำตาล
8. ใส่ใบกะเพราเป็นลำดับท้าย
9. คนให้เข้ากัน
10. ปิดไฟและตักใส่จาน

ข้อผิดพลาดหลักที่ระบบต้องตรวจ:

- ใส่ไก่ก่อนน้ำมัน
- ใส่ใบกะเพราก่อนไก่สุก
- เสิร์ฟทั้งที่ไก่ยังดิบ
- ปล่อยกระทะไว้นานจนอาหารไหม้
- ขาดวัตถุดิบหลัก
- วางวัตถุดิบชิ้นเดิมซ้ำเพื่อเพิ่มจำนวน

## บทพูด NPC ป้าแสง

### ก่อนรับภารกิจ

> สวัสดีจ้า วันนี้ช่วยป้าทำผัดกะเพราไก่สักจานได้ไหม เริ่มจากไปเก็บกะเพรากับพริกที่สวนก่อนนะ

ปุ่ม:

- `รับภารกิจ`
- `ขอดูรายละเอียด`
- `ไว้ทีหลัง`

### รายละเอียดภารกิจ

> เก็บกะเพรา 1 กำกับพริก 3 เม็ด แล้วกลับมาหยิบไก่และกระเทียมในครัว ล้างและเตรียมให้เรียบร้อย ก่อนนำไปผัดที่เตาจ้ะ

### คำแนะนำระหว่างทำ

- เก็บของไม่ครบ: `ลองกลับไปตรวจที่สวนอีกครั้งนะ`
- ก่อนล้าง: `วัตถุดิบจากสวนควรล้างให้สะอาดก่อนจ้ะ`
- ก่อนปรุง: `เตรียมทุกอย่างไว้ใกล้มือ จะได้ผัดต่อเนื่อง`
- ระหว่างปรุง: `รอให้ไก่สุกก่อน แล้วค่อยใส่ใบกะเพราเป็นอย่างสุดท้าย`

### สำเร็จ

> ทำได้ดีมากเลยจ้า ไก่สุกพอดีและใส่ใบกะเพราถูกจังหวะ ครบรสแบบไทย ๆ

### ผ่านแต่มีข้อแนะนำ

> ทำสำเร็จแล้วจ้า แต่ยังมีบางขั้นตอนที่ปรับได้ ลองดูคำแนะนำแล้วทำใหม่อีกครั้งนะ

### ไม่ผ่าน

> รอบนี้ยังไม่ผ่านจ้ะ ลองตรวจวัตถุดิบและลำดับการปรุง แล้วเริ่มใหม่ได้เลย

## Training และ Challenge

### Training Mode

- แสดง Objective และข้อความช่วยตลอดเวลา
- แจ้งเตือนก่อนทำลำดับที่ทำให้อาหารเสีย
- ไม่มีแรงกดดันด้านเวลา
- อนุญาต Reset เฉพาะขั้นหรือเริ่มภารกิจใหม่

### Challenge Mode

- แสดงเฉพาะ Objective หลัก
- ไม่เตือนก่อนทำผิด แต่บันทึกเหตุการณ์ไว้คิดคะแนน
- เริ่มจับเวลาหลังรับภารกิจ
- จบด้วยคะแนน รายการข้อผิดพลาด และคำแนะนำ

## Action Log Contract v1

```json
{
  "sessionId": "session-001",
  "timestampUtc": "2026-09-22T10:30:00Z",
  "action": "IngredientCollected",
  "ingredientId": "krapow_leaf",

  "stepId": "collect_garden",
  "stateBefore": "Raw",
  "stateAfter": "Collected",
  "isCorrect": true

```

```text
MissionAccepted
IngredientCollected
IngredientPlaced
IngredientWashed
IngredientCut
HeatChanged
IngredientAddedToPan

DishServed

```

## Definition of Done สำหรับเนื้อหา v1

- เล่น Training ตั้งแต่รับภารกิจถึงรับผลประเมินได้หนึ่งรอบ

- AI ล่มหรือยังไม่เชื่อม เกมยังจบภารกิจและแสดงผลได้
