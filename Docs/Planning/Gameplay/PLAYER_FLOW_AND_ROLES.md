# ลำดับการเล่น + บทบาทผู้ใช้

> ผู้ใช้ตัดสินใจ 9 พ.ย. 2026 (00:41–00:57) ในแชท M1 · ใช้แทนแนวคิดเดิมเรื่องล็อกอินนักศึกษา/PIN/ห้องเรียน (ตัดออกทั้งหมด)

## บทบาท (เหลือ 3)

| บทบาท | ใช้ที่ไหน | ทำอะไร |
|---|---|---|
| **ผู้เล่น** | แว่น VR (WebXR) + WebBoard | ใส่ชื่อ → เลือกเมนู → เล่น → ดูคะแนน/อันดับ · **ไม่มีบัญชี ไม่มีรหัส** |
| **อาจารย์** | WebBoard (ล็อกอินอีเมล) | ดูคะแนนผู้เล่นทุกคน · ค้นหาชื่อ · กรองตามวันที่/เมนู · ดูรายละเอียดรายคน (Action Log + คำประเมิน AI) · ส่งออก Excel |
| **แอดมิน** | WebBoard (ล็อกอินอีเมล) | ทุกอย่างที่อาจารย์ทำ + เพิ่มบัญชีอาจารย์ · เพิ่ม/แก้เมนู · ลบชื่อหยาบ/ข้อมูลขยะ · ตั้งค่าระบบ |

- **ไม่มีบทบาทนักศึกษา** · **ไม่มีห้องเรียน/รหัสห้อง** · **ไม่มี PIN**
- ชื่อผู้เล่นพิมพ์เอง เช่น `จิม432` · ชื่อซ้ำกันได้ (ระบบอาจเติมเลขท้ายภายหลังถ้าจำเป็น)

## ลำดับการเล่นในแว่น

1. **ใส่ชื่อ** (เช่น `จิม432`) — เครื่องจำชื่อล่าสุดไว้ ครั้งหน้ากดใช้ชื่อเดิมได้
2. **เลือกเมนู** บนกระดานสูตรอาหารข้างป้าแสง (เช่น ต้มยำกุ้ง)
3. **Training (โหมดสอน)** — เล่นก่อนเสมอ · ป้ายบอกขั้น + ป้าแสงเตือน · ไม่จับเวลา
4. จบ Training → หน้าผล + ปุ่ม **"ท้าทาย Challenge"** หรือ **"กลับไปเลือกเมนู"** (ผู้เล่นเลือกเอง ไม่บังคับ)
5. **Challenge** — ไม่บอกลำดับ · จับเวลา · ขอคำใบ้ได้ (หักคะแนน)
6. จบ Challenge → หน้าผล + **ตารางอันดับของเมนูนั้น** 🥇1 🥈2 🥉3 แล้ว 4, 5, ... (ไฮไลต์บรรทัดตัวเอง)

## กติกาตารางอันดับ (ข้อเสนอ ยังให้ผู้ใช้ยืนยันได้)

- แยก **ต่อเมนู** · นับเฉพาะ **Challenge**
- คนละ 1 บรรทัด = **คะแนนดีที่สุด** · คะแนนเท่ากัน → ใช้เวลาน้อยกว่าได้อันดับดีกว่า
- Training บันทึกเป็นสถิติ ไม่เข้าตาราง
- ไม่มีเน็ต → เล่นได้ครบ แต่ไม่ขึ้นตาราง (เก็บไว้ส่งทีหลังได้)

## งานแต่ละฝั่ง

- **M1 (เกม):** หน้าใส่ชื่อในแว่น · กระดานเลือกเมนู · ลำดับ Training → เลือก Challenge · หน้าผล + ตารางอันดับในเกม · ข้อมูลเมนูเป็นตาราง (หลายเมนู) · ส่งผล
- **M5:** แป้นพิมพ์/เลเซอร์ในแว่น · เรียก API บน WebXR
- **เว็บ (WebBoard + Netlify Functions + Supabase):**
  - ตาราง `players` (ชื่อ) · `sessions` (ผู้เล่น เมนู โหมด คะแนน 6 หมวด เวลา Action Log คำประเมิน AI) · `menus`
  - Supabase Auth เฉพาะอาจารย์/แอดมิน (role ใน `profiles`) · RLS: ผู้เล่นอ่านได้แค่ตารางอันดับ
  - API: `/api/sessions` (ส่งผล) · `/api/leaderboard?menu=` · `/api/menus`
  - หน้าเว็บ: ตารางอันดับสาธารณะ · หลังบ้านอาจารย์/แอดมิน
- กุญแจ (`SUPABASE_SERVICE_ROLE_KEY`, `GEMINI_API_KEY`) อยู่ใน Netlify Environment Variables เท่านั้น ห้ามอยู่ในเกม/แชท/commit
