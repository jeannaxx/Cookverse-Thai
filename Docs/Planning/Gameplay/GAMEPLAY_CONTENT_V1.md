- `IngredientIdentity` เก็บ `ingredientId` และ Instance ID แล้ว ยังรองรับชื่อเดิม `Krapow` / `Chili` ระหว่างเปลี่ยนผ่าน

## สถานะวัตถุดิบกลาง

ใช้ชื่อชุดเดียวกันทุก Script (ตรงกับ `IngredientState.cs`):

```text
Raw → Collected → Washed → Cut → AddedToPan → Cooking → Cooked → Burned → Served
```

กฎสำคัญ:

- วัตถุดิบหนึ่งชิ้นมี `ingredientId` เดียว และมี Instance ID สำหรับกันการนับซ้ำ
- `Washed` และ `Cut` ใช้เฉพาะวัตถุดิบที่ขั้นตอนกำหนด
- ไก่เปลี่ยนเป็น `Cooked` ได้เฉพาะเมื่ออยู่ในกระทะบนเตาที่เปิดไฟ ไม่สุกจากการรอเฉย ๆ
- เมื่อเป็น `Burned` แล้วห้ามย้อนกลับเป็น `Cooked`
- Reset ต้องคืนวัตถุดิบ ตำแหน่ง สถานะ จำนวน ระดับไฟ และ Objective ทุกอย่าง

## เตาแก๊สและความสุก

### ปุ่มบิด

ใช้ `XRKnob` จาก VR Template (`Assets/VRTemplateAssets/Scripts/XRKnob.cs`) ซึ่งให้ค่า 0–1 ตามมุมที่บิด แล้วแบ่งเป็น 4 ตำแหน่งที่ล็อกได้

| ตำแหน่ง | มุม | ตัวคูณความร้อน (ร่าง) | การแสดงผล |
|---|---:|---:|---|
| ปิด | 0° | 0 | ไม่มีเปลวไฟ |
| ไฟเบา | 60° | 1 หน่วย/วินาที | เปลวไฟเล็ก |
| ไฟกลาง | 120° | 2.5 หน่วย/วินาที | เปลวไฟกลาง |
| ไฟแรง | 180° | 5 หน่วย/วินาที | เปลวไฟใหญ่ |

ปุ่มควรมีเส้นผ่านศูนย์กลางประมาณ 8–10 ซม. และมีเสียงหรือการสั่นเบา ๆ ทุกครั้งที่ล็อกตำแหน่ง

### ความสุกของไก่ (ค่าร่าง)

- สะสมความร้อนเฉพาะเมื่อ **ไฟไม่ปิด และกระทะอยู่บนเตา** ยกกระทะออกหรือปิดไฟแล้วหยุดสะสมทันที
- `0` → `Raw` (สีชมพู)
- `1–99` → `Cooking` (ชมพูปนน้ำตาล)
- `100` ขึ้นไป → `Cooked` (สีน้ำตาลสุก)
- `160` ขึ้นไป → `Burned` (สีดำ มีควัน)

ตัวอย่างเวลา: ไฟกลางสุกใน 40 วินาที และไหม้ที่ 64 วินาที / ไฟแรงสุกใน 20 วินาที และไหม้ที่ 32 วินาที / ไฟเบาสุกใน 100 วินาที

ตัวเลขทั้งหมดปรับได้ใน Inspector และต้องลองบนแว่นจริงว่าเวลารอสั้นหรือยาวเกินไปหรือไม่

### ลำดับการปรุงที่ระบบกฎตรวจ

1. วางกระทะบนเตาและบิดเปิดไฟ
2. เติมน้ำมัน
3. ใส่กระเทียมและพริก
4. คนอย่างน้อย 1 ครั้ง
5. ใส่ไก่
6. ปรุงจนไก่สุก
7. เติมซอสหอยนางรม น้ำปลา และน้ำตาล
8. ใส่ใบกะเพราเป็นลำดับท้าย
9. คนให้เข้ากัน
10. บิดปิดไฟ แล้วตักใส่จาน

### ข้อผิดพลาดที่ต้องตรวจ

- ใส่ไก่ก่อนน้ำมัน
- ใส่ใบกะเพราก่อนไก่สุก
- เสิร์ฟทั้งที่ไก่ยังดิบ
- ปล่อยจนอาหารไหม้
- ไม่ปิดไฟก่อนเสิร์ฟ
- ขาดวัตถุดิบหลัก
- วางวัตถุดิบชิ้นเดิมซ้ำเพื่อเพิ่มจำนวน

## บทพูดป้าแสง

### ก่อนรับภารกิจ

> สวัสดีจ้า วันนี้ช่วยป้าทำผัดกะเพราไก่สักจานได้ไหม เริ่มจากไปเก็บกะเพรากับพริกที่สวนก่อนนะ

ปุ่ม: `รับภารกิจ` / `ขอดูรายละเอียด` / `ไว้ทีหลัง`

### รายละเอียดภารกิจ

> เก็บกะเพรา 1 กำกับพริก 3 เม็ด แล้วกลับมาหยิบไก่และกระเทียมในครัว ล้างผักและเตรียมให้เรียบร้อย ก่อนนำไปผัดที่เตาจ้ะ

### คำแนะนำระหว่างทำ

- เก็บของไม่ครบ: `ลองกลับไปตรวจที่สวนอีกครั้งนะ`
- ก่อนล้าง: `ผักจากสวนควรล้างให้สะอาดก่อนจ้ะ ส่วนไก่ไม่ต้องล้างนะ`
- ก่อนปรุง: `เตรียมทุกอย่างไว้ใกล้มือ จะได้ผัดต่อเนื่อง`
- ระหว่างปรุง: `รอให้ไก่สุกก่อน แล้วค่อยใส่ใบกะเพราเป็นอย่างสุดท้าย`

### ผลประเมิน

- สำเร็จ: > ทำได้ดีมากเลยจ้า ไก่สุกพอดีและใส่ใบกะเพราถูกจังหวะ ครบรสแบบไทย ๆ
- ผ่านแต่มีข้อแนะนำ: > ทำสำเร็จแล้วจ้า แต่ยังมีบางขั้นตอนที่ปรับได้ ลองดูคำแนะนำแล้วทำใหม่อีกครั้งนะ
- ไม่ผ่าน: > รอบนี้ยังไม่ผ่านจ้ะ ลองตรวจวัตถุดิบและลำดับการปรุง แล้วเริ่มใหม่ได้เลย

## Training และ Challenge

### Training Mode

- แสดง Objective และข้อความช่วยตลอดเวลา
- ป้าแสงเตือนทันทีเมื่อทำผิด และเตือนก่อนทำลำดับที่ทำให้อาหารเสีย
- ไม่จับเวลา
- เริ่มภารกิจใหม่ได้ตลอด

### Challenge Mode (ภาคเรียนนี้)

- แสดงชื่อเมนูและรายการวัตถุดิบ ไม่บอกลำดับขั้นตอน
- ไม่เตือนก่อนทำผิด แต่บันทึกทุกเหตุการณ์ไว้คิดคะแนน
- จับเวลาตั้งแต่รับภารกิจ
- มีปุ่มขอคำใบ้ หักคะแนนเล็กน้อยต่อครั้ง
- จบด้วยคะแนน รายการข้อผิดพลาด และคำแนะนำ

### Full Challenge (งานอนาคต)

ไม่มี Checklist และคำใบ้ระหว่างทำ ประเมินเมื่อส่งอาหารเท่านั้น

| เวลาและการทำซ้ำที่ไม่จำเป็น | 10 | ใช้เวลาสมเหตุผล ไม่ใส่ของซ้ำ (Challenge หักคะแนนคำใบ้ในหมวดนี้) |

ระดับผล: `80–100` ผ่านดีมาก / `70–79` ผ่าน / `50–69` ต้องฝึกเพิ่ม / ต่ำกว่า `50` ไม่ผ่าน

**เงื่อนไขบังคับ:** ถ้าไก่ยังดิบหรืออาหารไหม้ ให้ผล "ไม่ผ่าน" ไม่ว่าคะแนนรวมเท่าไร

### กรณีทดสอบคะแนน

ใช้ตรวจว่าระบบคำนวณคะแนนตรงกับ Rubric

| กรณี | ผลที่คาดไว้ |
|---|---|
| ทำถูกทุกขั้น | ผ่านดีมาก |
| ไม่ล้างผัก | หักหมวดการล้างและเตรียม |
| ใส่กะเพราก่อนไก่สุก | หักหมวดลำดับการปรุง |
| ไม่ปิดไฟก่อนเสิร์ฟ | หักหมวดความสุกและการใช้ไฟ |
| เสิร์ฟไก่ดิบ | ไม่ผ่าน |
| อาหารไหม้ | ไม่ผ่าน |

## Action Log Contract v1

ทุก Event มีข้อมูลอย่างน้อย:

```json
{
  "sessionId": "session-001",
  "mode": "Training",
  "timestampUtc": "2026-10-22T10:30:00Z",
  "action": "IngredientCollected",
  "ingredientId": "krapow_leaf",
  "instanceId": "krapow-plant-01",
  "stepId": "collect_garden",
  "stateBefore": "Raw",
  "stateAfter": "Collected",
  "value": null,
  "isCorrect": true
}
```

`value` ใช้เก็บค่าประกอบ เช่น ระดับไฟ (`0–3`) ใน `HeatChanged` หรือค่าความร้อนสะสมใน `FoodStateChanged`

Action ขั้นต่ำ:

```text
MissionAccepted       IngredientCollected   IngredientPlaced
IngredientWashed      IngredientCut         HeatChanged
IngredientAddedToPan  FoodStirred           FoodStateChanged
HintRequested         DishServed            MissionCompleted
MissionReset
```

## Definition of Done

- เล่น Training ตั้งแต่รับภารกิจถึงรับผลประเมินได้หนึ่งรอบ
- Objective เปลี่ยนตรงกับสถานะจริง และ Reset ได้
- ระบบเก็บกะเพรา/พริกเดิมยังผ่าน `M1CollectionSmokeTest`
- วัตถุดิบชิ้นเดิมไม่ถูกนับซ้ำ
- เสิร์ฟไก่ดิบหรืออาหารไหม้แล้วไม่ผ่าน
- คะแนนตรงกับกรณีทดสอบทุกกรณี
- AI ล่มหรือยังไม่เชื่อม เกมยังจบภารกิจและแสดงผลได้
