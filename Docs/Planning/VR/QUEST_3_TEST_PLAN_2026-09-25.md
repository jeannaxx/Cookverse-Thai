# Cookverse Thai — แผนทดสอบ Quest 3 วันศุกร์ที่ 25 กันยายน 2026

ขอบเขต: ทดสอบ M5 Environment/XR Foundation รอบแรก  
อุปกรณ์: Meta Quest 3 + Touch Plus Controller

> **สถานะวันที่ 26 กันยายน 2026:** เลื่อนการทดสอบ เนื่องจากยังไม่สามารถเดินทางไปใช้อุปกรณ์ Quest 3 ได้ ยังไม่มีผล Pass/Fail จากแว่นจริง และจะกำหนดวันทดสอบใหม่ภายหลัง

## เป้าหมาย

ยืนยันว่าขนาดบ้าน สวน บันได การเคลื่อนที่ Teleport และ Collider ที่ผ่าน Simulator แล้วใช้งานได้จริงบน Quest 3 รอบนี้ยังไม่ใช้ตัดสิน Hand Tracking, WebXR หรือ Gameplay Loop เต็มระบบ

## เตรียมก่อนวันทดสอบ

- [ ] Quest 3 ชาร์จแบตเตอรี่แล้ว
- [ ] มีสาย USB-C ที่ส่งข้อมูลได้
- [ ] เปิด Developer Mode
- [ ] อนุญาต USB Debugging ให้ Mac เครื่องนี้
- [ ] Unity Hub มี Android Build Support, SDK/NDK และ OpenJDK
- [ ] MainVR เป็น Scene แรกใน Build Profiles
- [ ] ตรวจ OpenXR Project Validation ไม่มี Error ที่กีดขวาง build
- [ ] Commit งานก่อน build และจด commit SHA
- [ ] สร้างโฟลเดอร์ build แยกจาก Assets เช่น `Builds/Quest3/`

## จุดวัดสำคัญจากของจริง

- ความสูงสายตาผู้เล่นเทียบกับพื้นบ้าน
- ความสูงราวเมื่อยืนบนบ้าน
- ความกว้างบันไดและความสูงแต่ละขั้น
- ระยะเอื้อมถึงเตา อ่าง โต๊ะกลาง และตู้เย็น
- ความกว้างทางเดินระหว่างบ้านกับสวน
- ความสูงของแปลงผักตอนก้มเก็บ
- ตำแหน่งเริ่มต้นหันเข้าหาภายในบ้านถูกทิศ

## เกณฑ์หยุดทดสอบทันที

- ภาพไม่ตามศีรษะหรือเกิดอาการผิดปกติรุนแรง
- ผู้เล่นเกิดใน Collider หรือตกใต้ฉาก
- Teleport ทำให้หลุดนอกพื้นที่
- Build ค้างหรือปิดตัวซ้ำ
- ผู้ทดสอบมีอาการเวียนหัวหรือไม่สบาย

## สิ่งที่ยังไม่ใช้ตัดสินในรอบนี้

- Hand Tracking แบบไม่ถือคอนโทรลเลอร์
- โมเดลมือใหม่
- WebXR
- ภารกิจผัดกะเพราเต็มวงจร
- ระบบคะแนนและ AI
