## ทำไมต้องมี WebXR

- แว่น Quest 3 ที่ใช้เป็นของอาจารย์ **Developer Mode เปิดได้เฉพาะบัญชีเจ้าของแว่น** บัญชีที่เพิ่มทีหลัง (ของเรา) ขึ้นป้าย "Developer mode is only available for device owners" จึงลง APK จาก Mac ไม่ได้ และ `adb devices` ว่างเปล่า
- WebXR เปิดผ่าน Meta Quest Browser ได้ทุกบัญชี **ไม่ต้องใช้สาย ไม่ต้องใช้ Developer Mode**
- เวอร์ชัน APK ยังอยู่ครบใน branch `feature/gameplay-content-ui` ใช้ได้เมื่ออาจารย์เปิด Developer Mode ให้

## ขั้นตอน Build และขึ้นเว็บ

1. อยู่บน branch `feature/webxr`
2. File → Build Profiles → **Web** → **Build** → โฟลเดอร์ใหม่ใต้ `Builds/WedXr/` (ไม่ commit, อยู่ใน `.gitignore`)
3. บีบโฟลเดอร์ที่มี `index.html` เป็น zip (ให้ `index.html` อยู่ชั้นบนสุดของ zip)
4. Netlify → โปรเจกต์ `candid-scone-736ec1` → แท็บ **Deploys** → ลาก zip ไปวาง (**อย่าใช้หน้า Drop ใหม่** จะได้เว็บใหม่ ลิงก์ใหม่)
5. รอ Published → ในแว่นปิดแท็บเก่า เปิดลิงก์ใหม่

## ข้อควรรู้

- **Netlify ใช้ระบบเครดิต:** เหลือ ~249 ณ 27 ต.ค. แต่ละ Deploy และการโหลดเกม (~28 MB/ครั้ง) กินเครดิต → รวมแก้หลายอย่างแล้วค่อย Deploy ครั้งเดียว ไม่ใช้ AI agent ของ Netlify ถ้าเครดิตใกล้หมด ย้ายไป GitHub Pages / itch.io ได้
- **Build ที่ถูกยกเลิก** อาจทิ้งไฟล์ XR Simulation ไว้ที่ `Assets/XR/Temp` (Git เห็นเป็นไฟล์ถูกลบ) → Build ให้สำเร็จอีกครั้ง Unity จะย้ายกลับเอง อย่า commit ระหว่างนั้น
- **เปิดบน Mac โดยไม่เข้า VR** กล้องจะอยู่ระดับพื้น (เพราะ Offset 0) เป็นเรื่องปกติจนกว่าจะแก้ข้อค้างด้านบน
- **ส่งภาพจากแว่นขึ้นมือถือ:** แอป Meta Horizon → Cast (Wi-Fi เดียวกัน) หรืออัดในแว่น ปุ่ม Meta → Camera → Record video
