## ขอบเขตใหม่ (ผู้ใช้ยืนยัน 4 พ.ย.)

ทุกข้อต้องเสร็จภายใน 30 พ.ย.:

1. **Gameplay ครบวงจร** ผัดกะเพราไก่: เก็บ → ตู้เย็น → ล้าง → หั่น → ผัด/ปรุง → จาน → เสิร์ฟ → คะแนน → หน้าผล → เริ่มใหม่
2. **Training Mode + Challenge Mode** ใน `MainVR`
3. **หลายเมนู** (จำนวนและรายชื่อรอยืนยันกับอาจารย์) — ระบบภารกิจเป็นตารางข้อมูลอยู่แล้ว เมนูที่ใช้สถานีเดิมเพิ่มเป็นข้อมูล + Prefab
4. **AI (Gemini ผ่านหลังบ้าน)** 3 งาน:
   - ป้าแสงคุย/สอนด้วย AI
   - AI จัดเมนูอาหาร (เลือกได้เฉพาะเมนูที่เกมมี)
   - AI ประเมินหลังเสิร์ฟ (อธิบายจาก Action Log + คะแนนระบบกฎ · **คะแนนมาจากระบบกฎ ไม่ใช่ AI**)
5. **WebBoard หน้าบ้าน + หลังบ้าน** (ย้ายจากภาคเรียน 2 มาภาคเรียนนี้)
6. **WebXR** เล่นจบทั้งสองโหมดบน Quest Browser + ผลทดสอบแว่นจริง
7. ส่วนที่ยังอยู่ภาคเรียน 2: โมเดลสวย Material แสง เสียง Animation

## โครงสร้างระบบ

```text
เกม Unity (Quest APK / WebXR)
   │  ผลการเล่น + Action Log (JSON)   ← ถ้าส่งไม่สำเร็จ เก็บในเครื่องแล้วส่งซ้ำ เกมต้องจบได้เสมอ
   ▼
หลังบ้าน API: Netlify Functions (เก็บ GEMINI_API_KEY ใน Environment Variables · ห้ามใส่ key ในเกม/ห้าม commit)
   ├── /api/ai/aunt     ป้าแสงคุย
   ├── /api/ai/menu     จัดเมนู
   ├── /api/ai/evaluate ประเมินหลังเสิร์ฟ (+ ข้อความสำรองเมื่อ AI ล่ม)
   └── /api/sessions    บันทึกรอบเล่น
   ▼
ฐานข้อมูล: Supabase (ฟรีเทียร์) — players · sessions · action_logs · results · menus · users(ครู/แอดมิน)
   ▲
หน้าบ้าน WebBoard (เว็บ, Supabase Auth) — อาจารย์ดูผล · แอดมินจัดการผู้ใช้/เมนู
```

AI: **Google Gemini 2.5 Flash-Lite / Flash** (ฟรีเทียร์ระหว่างพัฒนา · แบบเสียเงิน ~$0.10/$0.40 ต่อล้าน token) · สำรอง: DeepSeek
