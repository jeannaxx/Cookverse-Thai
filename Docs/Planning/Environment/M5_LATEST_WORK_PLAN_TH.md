# แผนงาน M5 ล่าสุด — บ้านและครัว Cookverse Thai

อัปเดตวันที่ 28 กันยายน 2026  
สถานะ: **เป็นแผนสำหรับทำต่อ ยังไม่ให้นำค่าชุดนี้ไปแก้ `MainVR` อัตโนมัติ**

## ข้อสรุปล่าสุด

- ใช้แปลนบ้านขนาด **8 × 6 เมตร**
- หน้าบ้านอยู่ฝั่งบันได และบันไดอยู่กึ่งกลางหน้าบ้าน
- บ้านยกพื้น โดยผิวพื้นบ้านสูงจากพื้นดินประมาณ **1.00 เมตร**
- ตัวบ้านเน้นพื้นที่โปร่ง ใช้ราวเตี้ยในบริเวณเปิด ไม่ทำผนังทึบปิดหน้าบ้าน
- หลังคาเป็นหลังคาทรงไทยหน้าจั่วตามภาพอ้างอิงล่าสุด
- ยังไม่ทำห้องนอนและไม่แยกห้องนั่งเล่นแบบปิด

## การแบ่งพื้นที่ภายในบ้าน

### ฝั่งซ้าย — NPC และมุมนั่งเล่น

- วาง `NPC_Area` สำหรับรับภารกิจและส่งงาน
- มีมุมนั่งเล่นขนาดเล็กอยู่ในบริเวณเดียวกัน
- จุดเกิดผู้เล่นอยู่บริเวณด้านบนของบันได และหันหน้าเข้าหา NPC

### ฝั่งขวา — ครัวหลัก

- ครัวเป็นรูปตัว **L** และมีโต๊ะเตรียมกลางครัว
- เตาอยู่ช่วงกลางของแนวครัว
- ด้านซ้ายของเตาเป็นพื้นที่เตรียมวัตถุดิบ
- ด้านขวาของเตาเป็นจุดวางอาหารที่ปรุงเสร็จ
- จุดวางจานอยู่ริมล่างฝั่งซ้าย เพื่อหยิบใช้ได้สะดวก
- ตู้เย็นรวมอยู่ในโซนวัตถุดิบ
- เว้นทางเดินหลักกว้างประมาณ **1.20–1.50 เมตร** เพื่อให้เดินและ Teleport ใน VR ได้สะดวก

## ลำดับ Gameplay ที่ต้องรองรับ

1. ผู้เล่นเกิดที่ชานหน้าบ้าน
2. คุยกับ NPC เพื่อรับภารกิจ
3. ไปหยิบหรือเก็บวัตถุดิบ
4. เตรียมและหั่นวัตถุดิบ
5. นำไปปรุงที่เตา
6. ตักใส่จานและนำไปยังจุดวางอาหารสำเร็จ
7. กลับไปหา NPC เพื่อส่งภารกิจและจบงาน

## งาน M5 ที่ยังค้าง

- ตรวจขนาดอุปกรณ์และระยะเอื้อมจริงเมื่อสวม Quest 3
- ตรวจ Android Build Support และ OpenXR
- Build APK และทดสอบบน Quest 3
- ทดสอบ Hand Tracking และ WebXR
- ปรับ Collider และตำแหน่ง Teleport หลังทดสอบด้วยแว่นจริง

## งานที่พักไว้

- ระบบจาก M1 และ Gameplay Loop เชิงระบบยังพักไว้ก่อน
- งานสวนทำหลังจากโครงสร้างบ้านและครัวลงตัว
